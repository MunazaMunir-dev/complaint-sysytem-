# complaint-sysytem-
About the Project
The Complaint Management System is a Full Stack Web Application that allows users to submit complaints, upload images, track complaint status, and manage their complaints through a user-friendly dashboard. An admin can manage all complaints and update their status.
This project was built to improve my Full Stack Development skills by working on both the frontend and backend.
